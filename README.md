# Vhukhudo Kevin Thamaga - Professional Portfolio

![Portfolio Screenshot](https://via.placeholder.com/1200x600/1E293B/2563EB?text=Portfolio+Preview)

## 🚀 Overview

This is a **complete, production-ready professional portfolio website** for Vhukhudo Kevin Thamaga, a final-year BSc IT student at North-West University.  
It features a **Matrix rain background**, glassmorphism, dark/light mode, animations, and a fully responsive design – all built from scratch with **HTML5**, **CSS3**, and **JavaScript**.

---

## ✨ Features

### 🎨 Design
- **Matrix Rain Background** (hacking/coding vibe) on hero section
- **Glassmorphism** UI with backdrop blur
- **Dark / Light Mode** toggle with local storage
- **Custom cursor** (desktop)
- **Modern typography** (Inter)
- **Soft shadows & gradients**

### 🧩 Sections
- Preloader, Sticky Nav, Hero (typed effect), About (animated stats), Skills (progress bars), Projects (cards with tech badges), Experience & Education (timelines), Certificates, GitHub (live repo fetch), Contact (cards + form), Footer.

### ⚡ Interactions
- AOS scroll animations, Typed.js, Matrix rain, Animated skill bars, Scroll progress, Back to top, Smooth scrolling, Mobile hamburger menu.

### 📱 Fully Responsive
- Desktop, Laptop, Tablet, Mobile.

---

## 🛠️ Technologies

- HTML5, CSS3, JavaScript (ES6)
- Font Awesome, Google Fonts (Inter)
- AOS, Typed.js, Matrix rain (canvas)
